Overview

Purpose

This is a software concept for a financial software application that would help users to eliminate their debt in with the help of modern technology. This software application is intended to be synchornized across all user preferred electronic devices that is connected to the internet for constant reminders. The main purpose of the application is to remind and motivate users to pay-off debts faster and with proper judgement.

Scenarios

  1. How can this app help me get out of debt?
  2. Will this tell me which debt I should pay first?
  3. Can it create a debt payoff plan for me?
  4. How long will it take me to become debt-free?
  5. Can I see how much interest I could save?
  6. What if I have a lot of different debts?
  7. What if I don't know exactly how much I owe?
